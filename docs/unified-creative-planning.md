# 统一创意工作流

## 统一创意生成、空档补全与修改反馈（2026-10-11，已部署，实模全链路待验收）

Kanban 确定策划后的内容生成与 MM 共用 User Assistant AI、amc-discovery / amc-creative Skill、逐条版本服务及 BrandKnowledge.marketingSolution 发布计划。月度频率定义期望排期，不再循环生成或覆盖整月内容。只保存原创意库中满足系统匹配标准且符合策划要求的品牌适配脚本；禁止为凑数降低标准、编造创意或以通用脚本代替未满足的策划要求。

用户发起匹配时持久化品牌、月份、策划快照、目标排期及操作者。每个 AI 任务最多三个候选，一轮可按剩余空档分批匹配，最多五批并服从既有 User AI 额度；结果允许为空；缺口保留为待匹配空档。按品牌时区每天夜间 01:00–05:59 启动有界补全，任务关页后继续，已有任务先核对结果。重试复用任务与保存回执；每条新脚本保存待审核版本，不覆盖旧稿或人工修改，不自动发布。策划发生变化须重新发起匹配；过期排期不静默移动。系统故障与匹配不足分别展示。

匹配不足时固定提示：暂未找到更多满足策划要求的创意，已保留排期空档。系统将在每天夜间继续匹配，符合要求后自动补充，供你审核。

两端编辑入口展示原创意 ID、标题、可用来源链接和摘录快照，明确来源完整性；支持相同字段编辑、保存、版本差异及 AI 修改指令。版本记录真实操作者、父版本、字段差异、可选修改原因及 AI 指令/产物引用。用户采用候选后才更新当前版本，冲突保留输入；记录原因与观察到的字段变化分开，不从文本差异推断故障原因。按品牌汇总修改最多的字段及用户标记的 SKU、镜头衔接、画面描述、口播、品牌事实等原因，支持回看版本证据。

验收：20 个目标仅匹配 8 条时保留 12 个空档；零匹配显示固定提示；异常不冒充零匹配；夜间补全、重启、重复点击、并发保存及撤权不重复或越权；两端回读同一创意版本；已修改内容不被补全覆盖；原创意、AI 产物与人工差异可追溯。实现及本地测试不代表线上已部署或生产全链路验收。


实现边界：通用创意池每日额度与已确定策划的匹配请求分别记账；策划请求使用既有用户额度，每批最多三条、每天最多五批。只有已检查完有空档的平台后才显示匹配不足，额度耗尽显示等待下一夜。匹配输入提取目标月份季度与月度要求；完整策划快照保留用于保存时一致性检查，过长的当月要求明确拒绝，不静默截断。
