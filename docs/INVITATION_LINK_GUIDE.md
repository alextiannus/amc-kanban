# 邀请链接功能文档

## 功能概述

添加新用户后，系统会自动生成一个**邀请链接**。该链接包含：
- ✅ Kanban 应用 URL
- ✅ 用户名（邮箱）
- ✅ 临时密码
- ✅ 欢迎介绍语

## 使用流程

### 1. 管理员创建新用户

在 `/admin` 页面：
1. 填写用户邮箱
2. 选择用户类型（Human User 或 AI Agent）
3. 点击 "Add" 按钮

### 2. 自动生成邀请链接

创建成功后，会弹出邀请链接模态框，显示：
- 用户邮箱
- 临时密码  
- **邀请链接**（核心功能）

### 3. 管理员复制和分享

- **复制单项**：点击各项右侧的"复制"按钮
- **复制全部**：点击"复制全部信息"按钮
- **通过链接分享**：将邀请链接发送给新用户

### 4. 用户访问邀请链接

新用户点击邀请链接后：
- 访问 `/invite/[token]` 页面
- 看到完整的欢迎页面，包括：
  - 欢迎标题和介绍
  - 邮箱和临时密码（可复制）
  - 重要提示（密码仅显示一次）
  - "前往登录"按钮

### 5. 用户登录系统

用户点击"前往登录"后：
- 跳转到登录页面 `/`
- 使用邮箱和临时密码登录
- 登录成功后建议修改密码

### 邀请链接生成流程

1. **生成临时密码**
   - 使用 `crypto.randomBytes(18)` 生成随机密码
   - Base64 URL 编码

2. **加密用户信息**
   - 使用 AES-256-CBC 加密
   - 包含：email、username、password、welcomeMessage、createdAt
   - 结果编码为 base64url token

3. **构建邀请链接**
   - 格式：`{KANBAN_URL}/invite/{token}`
   - KANBAN_URL 来自环境变量 `NEXT_PUBLIC_KANBAN_HOST`

4. **返回给管理员**
   - API 返回完整的邀请链接
   - 前端显示在模态框中

### 环境变量配置

需要配置以下环境变量：

```env
# 必需：Kanban 应用的基础 URL
NEXT_PUBLIC_KANBAN_HOST=https://your-kanban-domain.com

# 可选：邀请链接加密密钥
# 默认：自动生成（不建议在生产环境使用）
INVITATION_ENCRYPTION_KEY=your-32-byte-hex-key
```

**重要**：
- `NEXT_PUBLIC_*` 前缀的变量会暴露到客户端，但这里只包含 URL
- `INVITATION_ENCRYPTION_KEY` 应该在服务器端保密
- 如果不设置加密密钥，系统会自动生成，但重启后会改变（导致旧链接无法解密）

### 邀请链接有效期

- **有效期**：7 天
- **验证**：在邀请页面加载时检查
- **过期处理**：显示"邀请链接已过期"错误

## 安全性考虑

1. **密码安全**
   - 临时密码使用加密算法生成
   - 仅在创建时显示一次
   - 用户登录后应立即修改

2. **链接加密**
   - 使用 AES-256-CBC 加密敏感信息
   - IV（初始化向量）随机生成
   - 无法伪造或篡改链接内容

3. **链接过期**
   - 7 天自动过期
   - 防止旧链接被滥用

4. **URL 安全**
   - 使用 Base64URL 编码
   - 可安全在 URL 中传输

## 故障排查

### 1. 邀请链接无法解密

**原因**：
- 加密密钥改变
- 链接被篡改
- 链接过期（>7 天）

**解决**：
- 管理员重新生成邀请链接
- 确保 `INVITATION_ENCRYPTION_KEY` 保持一致

### 2. 邀请页面显示空白

**原因**：
- Token 无效
- 解密失败

**解决**：
- 检查浏览器控制台的错误信息
- 确认邀请链接完整性
- 重新生成邀请链接

### 3. 登录页面跳转失败

**原因**：
- 路由配置问题
- 浏览器 JavaScript 被禁用

**解决**：
- 检查浏览器 JavaScript 启用状态
- 手动导航到 `/` 页面

## 最佳实践

1. **管理员操作**
   - 复制完整的邀请信息
   - 通过安全通道（邮件/通讯软件）发送给新用户
   - 不要在不安全的地方存储密码

2. **用户操作**
   - 点击邀请链接查看完整信息
   - 复制邮箱和临时密码
   - 点击"前往登录"按钮
   - 登录后立即修改密码

3. **系统维护**
   - 定期检查 `INVITATION_ENCRYPTION_KEY` 配置
   - 监控过期邀请链接
   - 定期更新临时密码生成算法

## 常见问题

**Q: 邀请链接可以转发给其他人吗？**
A: 可以。邀请链接本身不记录领取者，任何有链接的人都可以看到用户凭证。建议通过私密方式分享。

**Q: 忘记临时密码怎么办？**
A: 管理员需要重新生成邀请链接，或者通过其他管理工具重置用户密码。

**Q: 可以修改欢迎语吗？**
A: 目前使用固定模板。如需自定义，可修改 `src/lib/invitation.ts` 中的 `welcomeMessage` 部分。

**Q: 邀请链接过期了怎么办？**
A: 管理员在管理页面重新添加用户，系统会生成新的邀请链接。
