# Admin 品牌主理人指派

状态：已部署生产，2026-09-21。客户页面不变。

Admin → 品牌管理 → 编辑品牌 →「品牌主理人 · 运营负责人」，从已保存的有效团队中选择一位启用的人类非 OWNER 成员，选择后由底部“保存修改”统一提交。原主理人降为 EDITOR 并保留团队身份，不自动授予全局角色。无订阅及免收订阅品牌也支持指派；运营看板继续只读。

品牌表单通过 PATCH /api/admin/brands/{id} 在同一事务保存 principalId/principalVersion 与品牌资料，仅提交变更字段。候选查询沿用 GET /api/admin/brands/{id}/principal；旧独立接口兼容保留，界面不再调用。

管理员会话接口 GET/PATCH `/api/admin/brands/{id}/principal`；PATCH 校验 Origin、真实团队资格及完整成员版本，串行化事务更新角色并审计，冲突要求刷新。原运营接口保留其显式 AMC_PRINCIPAL 候选限制，更换后同样保留原成员为 EDITOR。

修复普通品牌保存将全体团队成员写成 EDITOR 的问题，并阻止直接移除现任主理人。品牌列表从 Crew 返回真实成员，保存失败不关闭编辑面板。没有数据库迁移。
