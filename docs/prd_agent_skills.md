# Agent 与 Skills 管理

状态：2026-10-19 已发布；安装管理经本地数据库及浏览器回归，生产运行配置和实际营销 Skill 加载经真实品牌任务验证。

AMC 看板提供 `/agents`，管理员查看全部已注册 AI Agent 及本仓内置工作流节点、User AI、Platform AI 与独立工程复审模型；其他用户沿用已注册 Agent 可见范围。全局内置 Skills 仅管理员可改；已注册 Agent 的配置也仅管理员可改，自身可通过认证 API 读取有效 Skills。页面不声称能扫描外部设备中的技能。

支持查看完整 Markdown、编辑、安装自定义 Markdown Skill、从内置目录安装和卸载。Skill 不授予工具或业务权限；不运行上传脚本。内置文件是默认版本，数据库保存覆盖和卸载标记，重启后不丢失；卸载不删除共享源文件。修改使用版本校验，冲突返回 409，保留用户输入；每次变更与审计同事务。自定义文件限 60 KB；恢复与服务器内置版本逐字一致的 Skill 可使用该内置内容的原大小，不能借此上传超限自定义内容。路径只接受小写 slug/SKILL.md，不允许遍历。

内置 User AI 和 Platform AI 在技能发现和读取时加载最新有效配置；年度营销适配器使用相同内容与版本。文案节点的平台技能读取同一配置；委托 Content 服务的生成仍使用该服务配置，页面明确区分。公开 Markdown/ZIP 分发继续提供发布包默认版本，私有数据库覆盖仅通过鉴权管理 API 获取，不公开管理者新增内容。其他不消费 Markdown 的确定性工作流节点只展示说明，不提供无效安装按钮。外部注册 Agent 通过自身认证的 Skills API 获取配置，页面明确提示外部运行端需要接入，不能将配置已保存说成远端已执行。

新配置影响后续读取，不改写历史产物。新对话受理前核对必需 Skill 已安装；缺失时不调用模型，返回明确错误。原任务重试仍复用已受理记录；运行期间卸载被任务要求的 Skill 后明确报缺少 Skill，不静默使用已卸载的默认版本。MM 运行配置展示已安装状态与版本，不暴露私有 Markdown；安装仍由管理员在原 Agent 管理入口完成。品牌策划缓存版本包含当前 Skill 内容摘要。

接口：GET /api/agent-skills 返回有权限的 Agent、有效技能和内置目录；GET /api/agent-skills?agentId=... 返回单 Agent。POST /api/agent-skills 接收 agentId、skillId、action（save/uninstall）、content（save）、expectedVersion。管理员写入；未认证 401、无权限 403、未知 Agent 404。外部 Agent 使用原个人 API Key 调用 GET，仍按角色及授权关系限制可见范围；管理员可查看全部。

验收：权限隔离、安装/编辑/卸载/重装、并发冲突、事务审计、路径与大小限制、运行端加载和卸载生效、缓存失效、手机和桌面布局、错误保留输入。不通过本次测试调用真实付费模型或发布内容。
