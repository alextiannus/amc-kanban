## 对话驱动的品牌营销策略（2026-10-19 已上线）

用户通过同一工作空间制定品牌营销策略、补充约束和持续修改。每次有效结构化策略自动保存并回读核对，不增加人工审批、采用按钮或二次确认。比较版本用于理解变化，不是保存门槛。保留原有营销策略模型、版本记录、权限、幂等和冲突检测。保存策略不启动付费制作、广告投放或对外发布。

任务与会话分别持久化：会话按当前用户与品牌隔离，可以列出、恢复和继续；资料刷新不另起会话。历史来自已授权任务，不能把浏览器文本当作保存回执。较早消息通过游标分页查阅，支持按消息关键词查找会话；模型继续使用有界历史、阶段摘要及当前正式策略，不声称无限上下文。运行中允许停止及补充要求；补充以明确的后续任务处理，界面准确区分补充尚未生效与已生效，不能假装修改了正在生成的模型上下文。

进度来自授权任务状态及只含名称/状态的工具回执；支持流式的策略供应商可显示绑定当前任务路径与品牌的正文预览，明确标记尚未核对或保存。不返回原始工具参数、推理或未经确认的完成状态。任务完成后即使页面已关闭，由服务端完成处理执行策略自动保存；网络失败重试原操作，冲突保留原结果与当前正式版本并提示继续修改，不盲目覆盖。返回保存版本、时间、当前是否仍为该版本及变更摘要。

会话恢复完善（2026-10-19 已上线）：自动保存处于重试状态时，只读取原任务核对回执，不重新生成；读回成功后更新本轮保存状态。查阅更早消息不停止当前任务、不丢失未发送输入，并保持阅读位置；只有接近底部时新回复才自动跟随，离开底部可一键回到最新消息。当前阅读中已加载的消息不因新回复而裁剪，本机恢复缓存仍保留最近 40 条消息，模型历史预算保持不变。会话搜索采用最新请求结果，过期响应不得覆盖新搜索或切换后的会话。

成果连续性与回执（2026-10-19 已上线）：完成后的下一轮修改也关联同会话上一任务，服务端提供原成果及尚未保存的结构化方案，并以当前正式策略核对修改。每轮已核对的保存回执在聊天中显示版本、保存时间和实际变更章节；未知章节不展示技术字段，不把生成文本当作保存凭证。历史恢复沿用同样的回执展示，无审批操作。

Agent 工作台（2026-10-19 已上线）：聊天内可打开任务中心，查看本人当前品牌的任务、翻页、恢复会话及读取原结果；停止只操作选定任务，使用稳定操作键。运行详情显示已授权工具回执的名称与状态、固定 workspace 产物引用、实际加载的 Skill 摘要、账本 token 用量和待结算状态，不暴露工具参数、正文、推理或凭据。运行配置展示有效 Skill 安装状态及现有计量政策；全局 Skill 安装仍仅管理员通过原入口操作。新对话缺少必需 Skill 时在模型调用前拒绝，原已受理任务重试继续复用。工作偏好直接接入原修订校验编辑器；每轮读取用户当前偏好作为偏好而非事实或授权。用量计量不虚构余额、金额或硬额度。运行轮次、调用次数与执行时限由执行器和界面共用配置；偏好切换品牌时清除旧待提交操作并忽略迟到回执。

验收覆盖：同一品牌连续制定和修改、保存读回、并发冲突、丢回执重试、页面关闭后保存、跨设备恢复、不同品牌和用户隔离、补充/停止、320/390/768/1440布局。记录首个反馈耗时、完整任务成功率和恢复结果，模拟测试与真实模型/生产证据分开。

## 一、产品定位

**AMC-MM（AI Marketing Companion — Merchant Mode）** 是 AI Marketing Crew 为品牌主设计的移动端专属应用。

## 三、设计原则

1. **AI 优先**：所有操作都可以通过对话触达，功能模块是对话的可视化辅助
2. **主动汇报**：AI 主动说话，不等用户问
3. **最少点击**：审批、确认类操作应在对话流中完成，无需跳转
4. **移动优先**：设计以手机竖屏为基准，所有交互适配拇指操作区

### 🅳 P0 — 功能 D：主动开场白（Proactive AI Greeting）

**描述**：每次品牌主打开 AMC-MM，AI 伴侣**主动开口说话**，汇报当前最重要的工作状态，无需用户主动提问。

**开场白逻辑**（优先级检查顺序，取前 1-2 条拼成开场白）：

```
1. 🔴 有待审批草稿（ActionItems pending）
   → "老板好，有 X 篇内容准备好了等您确认。"

2. 🟡 品牌内容健康异常（某平台超过 3 天未发布）
   → "另外，[平台] 已经 X 天没更新了，要我帮您写一篇吗？"

3. 🟢 今日排期提醒
   → "今天 [时间] 有一篇 [平台] 内容将自动发布。"

4. ⚪ 无特别事项
   → "一切正常，今日暂无待处理事项。有什么需要我帮忙的吗？"
```

**个性化**：
- 开场白使用品牌名称
- 根据品牌 tone of voice 调整说话风格（正式/活泼）
- 时段感知：早上/下午/晚上使用不同问候语

**触发时机**：
- 页面首次加载时（每次打开 app）
- 用户在主界面停留超过 30 秒无操作时重新提醒

**技术要求**：
- 页面加载时并行调用：`/api/brands/[id]/actions`、`/api/dashboard/calendar`、`/api/dashboard/brand-activity`
- 将汇总数据作为 context 传给 AI，生成个性化开场白
- 自动触发 TTS（文字转语音）播报
- 头像同步进入"说话"表情状态

**验收标准**：
- [ ] 每次打开页面，AI 在 2 秒内开始说话
- [ ] 开场白准确反映当前实际数据状态
- [ ] 有待审批时，开场白必须提到
- [ ] 品牌超过 3 天未发布时，开场白必须提到

### 🅲 P1 — 功能 C：对话式草稿审核（Conversational Draft Approval）

**描述**：品牌主可以通过自然对话直接审批或拒绝 AI 生成的内容草稿，无需跳转到单独的审批页面。

**完整对话流程示例**：

```
AI（主动）: "老板，我给小红书写了一篇关于周末特惠的内容，您要听一下吗？"
用户: "说来听听。"
AI（读草稿）: "周末限定！波士顿大龙虾买一送一，仅限堂食。带上家人一起来，让每个周末都变得特别。📍[地址]"
用户: "发出去吧。"
AI（执行）: "好的！已安排在今天下午 6 点发布到小红书。"

---

用户: "重新写，改成更接地气的风格。"
AI（执行）: "收到！我来重新写一版..."
```

**支持的审核指令**：

| 用户意图 | 示例话术 | AI 执行的操作 |
|---------|---------|------------|
| 批准并发布 | "发出去"/"可以"/"就这样" | 调用 `/approve` API |
| 批准但调整时间 | "明天早上 10 点再发" | 更新 scheduledAt + approve |
| 拒绝重写 | "重新写"/"风格不对" | 调用重新生成 API |
| 拒绝并放弃 | "算了，先不发这篇" | 将草稿标记为 archived |

**多轮上下文与持久任务（升级目标，待实施）**：
- 前端可维护会话展示缓存；服务端通过 Core 持久 Task 记录原目标、补充输入和仍有权读取的业务引用。
- “刚才那篇”由显式 taskId、brandId、draftId 或 creativeRevisionId 解析；对话 history 只用于理解，不作为写入对象、权限或版本的权威依据。
- 写入前检查当前用户品牌权限及目标版本；重启或换设备后续接原任务，未知写入先按原回执查询。
- 当前日历编辑路径与目标之间的差距、Core 依赖选择和验收要求见上述升级设计。

**验收标准**：
- [ ] 用户说"发出去"时，AI 能识别并调用正确的 draftId approve API
- [ ] 用户说"改成明天发"时，AI 能正确更新排期时间
- [ ] 用户说"重新写"时，AI 能重新生成内容（保留品牌上下文）
- [ ] 多轮对话中 AI 始终记住当前讨论的是哪篇草稿

素材上传采用前后端双重校验：AMC-MM 在申请直传地址之前先检查文件类型、大小及可读取的图片/视频参数，服务端在确认上传时重新读取 OBS 原文件并以服务端结果为准。图片仅接受 JPEG/PNG/GIF/WebP 且不超过 10 MB，视频仅接受 MP4/MOV/WebM 且不超过 250 MB；不合规文件返回结构化错误，不自动裁剪、压缩或转码。发布时由 AMC 后端再按目标平台检查 Instagram/TikTok 参数，平台建议的图片/视频格式、大小、尺寸、比例、编码、帧率和时长仅返回 warning 并继续提交；无素材、媒体混合、数量非法、文件损坏或源文件不可访问仍阻止发布。历史图片超过 10 MB 时允许发布前读取并提示。Instagram 草稿可选 `TIMELINE`、`REEL` 或 `STORY`；未选择时单视频默认作为 `REEL`，其他合法图片组合默认作为 `TIMELINE`，且服务端在发布前校验发布类型与媒体组合兼容。

## 十一、任务与对话持久化

AI 工作真值由 Kanban 托管的 IAIC Task、Session、Memory 与 Workspace 保存。浏览器缓存仅用于显示，不以异步写聊天记录替代任务接受回执。任务提交返回持久 taskId；刷新、切设备和关页不取消已接受任务。补充资料回到同一任务，继续动作使用稳定请求键及 Core 原操作回执。

旧 companion 对话与 persona 保留兼容；未迁移的闲聊历史不冒充可恢复业务任务。权限撤销或切品牌后清理当前显示并按新范围重读。任务、审计与来源的保留遵循各自业务规则，不套用旧“30天/500条聊天自动归档”设想。

当前改造状态、接口与验收以 [IAIC 改造实施设计](amcmm-iaic-implementation.md) 为准。制作、批准及发布分别授权，模型返回 action 不构成执行权限或成功证据。

## User AI / API Key 同权契约（2026-10-01，权限底座已上线，完整验收进行中）

用户自己的 AI 助手使用 UserApiKey，代表 Key 所属用户调用其全部已授权业务能力。UI、REST、MCP、内置 User AI 与外部助手共享当前用户角色、品牌范围、领域规则及结果，不因 api_key 来源降权、另设 Agent 白名单或注册要求，也不获得额外权限。Cookie、Bearer 和 x-api-key 是认证方式而非业务权限。显式凭证无效时不得回退另一有效 Cookie；停用用户、Key 撤销/过期和角色/品牌撤权必须对下一次动作生效。内部 Content 服务 Token 不能代替用户授权；下游身份票据保留来源及 credentialId 并重新校验撤销状态。

访谈信息整理当前实现（2026-10-18，本地验证通过）：由 AMC 营销策略 Skill 统一整理最新 AI Insight、现有品牌资料和最新访谈/补充记录，输出“当前信息 → 希望补充的信息”。只按报告、品牌资料和最新访谈三个来源的版本复用真实 IAIC 任务；其中任一变化才更新品牌定位受影响的部分，保留其他已确认内容。每次实际整理使用当前 Skill；Skill/月份/语言变化本身不触发重写。整理完成自动保存为当前品牌定位，不设采用或审核按钮；保留用户明确事实。来源变化时不得保存旧整理结果。

品牌访谈的产出为品牌定位（兼容 coCreation.interview 存储）。完整营销策略使用当前可用品牌定位、真实当地节假日与节点、主理人策略输入，并依据社交平台默认定位规划内容类型和活动节奏；Subscription 暂不作为策略输入，不规定各平台具体发布次数；不可读和缺失保留待确认。主理人策略输入另行编辑，不触发品牌定位更新；方案按变化的输入继续优化，旧定位不被反复改写。


Skill 分步交付规范（2026-10-18，规则文本更新，尚未验证本次生产部署）：三步均规定 Input、必须完成动作、Output 内容与格式、完成条件；正式文档使用可编辑 Markdown，宿主结构化输出仍严格遵守原 schema。品牌定位须包含商家忌讳词汇、禁用说法、适用范围、替代表达及来源/确认状态，未提供列为待补充；后续方向、卖点和策略继承表达边界。完整策略须包含当地节庆及日期来源，每项拟执行节庆活动至少提前两个日历月启动策划，并给出里程碑；期限已错过标明准备期不足及调整建议。按活动列明门店配合动作、商家/销售/主理人/AMC AI责任角色、截止日、资源、验收及确认状态。全年12个月与滚动连续六个月均保留；Subscription和平台具体发布次数仍不作为策略输入。规则不等于模型输出已通过生产验证。


## AMC Skills 统一包

## 策略内容方向、执行创意匹配与专业表达（2026-10-19，实施中）
生成品牌营销策略时不检索或匹配创意库，不展示匹配推荐；策略仅确定品牌内容方向、月度活动主题、平台形式及素材要求。创意检索留到制定次月内容计划和组织内容制作等执行工作，按当前可执行策略、当月活动、商品和平台筛选真实来源，保留链接、匹配依据及查询时间，不冒充热度、授权或已制作。执行创意每日先进入按匹配度排序的品牌创意列表，全部候选须用户 Like 选入，再显式复刻；不自动设置发布时间；来源更新不触发本地化或制作，策略页仅提供说明与品牌创意入口；失败保留旧结果和真实状态，不重写整份策略。
策略以专业营销顾问的自然表达交付：先写结论，再说依据、推广安排和观察指标；少用缩写、口号和内部机制词。避免“赋能、抓手、闭环、心智占领、流量承接、拉通”等空泛表达；改为具体客群、商品、渠道、行动和结果。SWOT 等必要术语可保留并解释。生成完成前逐段检查、删去重复和无依据断言，保留原有事实、时间、范围与不确定性。

海外平台策略（2026-10-19，实施中）：小红书优先当地华人发现与适用UGC/KOL体验；TikTok和Instagram Reels优先本地新客发现；Instagram图文作为独立站延伸，展示产品、服务、门店并提供真实WhatsApp/官网入口；Google Maps结合完整商家资料、附近搜索与真实店内活动。每月更新活动计划，当月活动主题在包括Google Maps的各已启用可发布渠道至少一次，可按需要多次；这是活动覆盖要求，不是平台总发帖配额，不另拆平台Todo。Google付费曝光依据资格、目标和已获授权预算选择，不能混同自然排名。每次月度复盘用可读取的实际表现修正平台分工，保留经验判断和官方事实的来源。

策略版本记录按当前品牌隔离：切换品牌立即隐藏上一品牌缓存，迟到请求不得覆盖当前品牌结果；同品牌刷新保留已加载版本。
