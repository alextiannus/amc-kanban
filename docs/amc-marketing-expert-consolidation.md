# AMC 营销专家与年度策划合并

状态：2026-10-14，已实现，等待本次生产部署。

原看板年度策划不是独立 Skill，而是 `brand-plan/service.ts` 加数据库提示词 `marketing_plan_generation` 的工作流。与 AMC 营销专家在调研输入、品牌访谈、卖点识别、年度主线、季度和月度方向上高度重叠；不能用代码文本相似率代表功能重复度。

| 能力 | 合并后的归属 |
| --- | --- |
| Insight、访谈、宣传重心和卖点共创 | `skills/amc-marketing-expert/SKILL.md` |
| SKU 优先级、平台分工、订阅边界、运营反馈 | 同一 Skill，移除旧生成器独立规则 |
| 年度策略＋四个季度的结构化输出 | `brand-plan/marketingExpert.ts` 读取同一 Skill，提供原数据格式约束 |
| 保存计划、历史版本、研究快照关联 | 原 `runBrandPlanAction`，沿用原数据和权限 |
| 站内继续讨论旧策划 | `amc.marketing_workspace` 读取当前品牌已有访谈、主张和年度计划 |
| 外部 Assistant 安装 | 标准 Skill ZIP；通过原 Personal MCP 读取和正式生成保存 |
| 月度内容计划、内容生成与发布 | 原后续流程，非年度策划的自动附带动作 |

原 REST、MCP 和看板入口保持兼容；旧 `amc-brand-planning` 为兼容转发。数据库旧提示词保留历史，但不再加载、不再显示为有效可编辑模板，也不能重新创建同名模板。生成日志保留 Skill 路径和内容哈希，便于核对规则来源。

站内对话结果仍为讨论稿；读取旧计划不会改写它。需要落库时，通过看板访谈保存、年度生成或编辑操作执行；外部 Assistant 使用已有正式 MCP 动作，不把生成后的新内容冒充逐字保存的对话草案。
