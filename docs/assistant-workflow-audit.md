执行原则：不引导用户填写能用对话完成的表单；系统缺少能力时如实说明。新工具必须使用当前用户与固定品牌权限，禁止凭模型传入的brandId跨品牌。尚未接入的能力不宣称已实现。

本次代码审查修复：审计JSON类型、读取结果反复重查造成的延迟、业务回执缺失、写入后回复失败仍提示重发。回执明确区分已保存、已受理、失败和结果未知。真实生成模型与外部服务不在本地模拟测试的证明范围内。
