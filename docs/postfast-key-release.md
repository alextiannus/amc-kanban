# PostFast Key 解绑并回池

状态：已部署生产，2026-09-20。

管理员在系统设置的 PostFast Key 池对已分配的 Key 选择「解绑并回池」。操作要求 PostFast 工作区无连接账号、无远端排期，品牌无本地排期或执行中的发布任务；查询失败保持原绑定。操作不撤销远端授权、不删除历史内容，不自动对任何品牌执行回池。

接口：`PATCH /api/admin/postfast-keys`，请求包含 `id`、`action: "release"`、`expectedBrandId` 和列表返回的 `expectedUpdatedAt`。版本变化返回 409，包括同品牌重新分配；已处于空闲库存的重复请求幂等成功。成功原子清空品牌配置与同步缓存、清除分配信息、关闭相关自动发布并记录脱敏审计。

审查修复：

- 增加分配版本校验，避免旧页面解除重新分配给同一品牌的新绑定。
- 解绑请求 30 秒超时；列表刷新 15 秒超时，审计列表刷新不再阻塞解绑按钮恢复。网络失败要求刷新确认结果。

验证：回池成功、重复调用、版本冲突、权限、未完成任务、远端失败、历史保留、脱敏和事务失败回滚测试通过（事务回滚测试使用内存模拟）。PostFast 集成、账号解绑、大视频投递回归测试通过。TypeScript 和 API 文档检查通过；新增服务 ESLint 通过，既有文件的存量 lint 问题未增加。无需新增数据库迁移。
