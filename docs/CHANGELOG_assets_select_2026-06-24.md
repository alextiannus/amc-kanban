# 素材库多图选择体验优化 — 2026-06-24

根据用户反馈，优化了素材库中鼠标拖拽/滑动选择多张图片的交互设计。

## 变更明细

### 1. 拖拽冲突修复 (Draggable Conflicts Fixed)
- **动态 Draggable 锁定**：新引入 `isSelectingState` 状态，当用户在任一复选框（Checkbox）上 `onMouseDown` 触发拖拽选择时，该状态置为 `true`。
- **防止 HTML5 拖拽干扰**：当该状态为 `true` 时，所有素材卡片的 `draggable` 属性动态设置为 `false`。
- **优点**：彻底规避了浏览器原生 HTML5 拖拽图标和预览半透明层启动，从而使得鼠标移动时所有卡片的 `onMouseEnter` 事件能够百分之百准确触发，实现了顺畅无比的拖拽多选效果。鼠标/手指抬起时自动恢复 `draggable={true}`，不影响原有的拖拽到文件夹分类功能。

### 2. 交互区域与视觉强化 (Hitbox & Visibility Upgrades)
- **增大热区**：复选框的外观及命中点击热区由原先的 `w-5.5 h-5.5` 增大至 `w-6.5 h-6.5` (26px)，图标增大为 `w-4 h-4`，使用户更容易点中并触发滑动。
- **选择模式感知**：一旦选定任意一个素材（`selected.length > 0`），所有未选素材的复选框立即由隐藏状态（`opacity-0`）变为常显半透明状态（`opacity-100`），使用户非常清楚当前正处于多选模式下。

### 3. 全卡片点击多选模式 (Card Click Selection)
- **快捷点选**：当多选模式开启时 (`selected.length > 0`)，用户点击卡片上的任何区域（如图片中部）都会直接触发选择/取消选择，不需要再精确瞄准左上角小复选框。

### 4. 键盘 Shift-Click 连选 (Shift-Click Range Selection)
- **区域连选**：实现了类似桌面管理器的 Shift + 点击多选体验。当用户选中一个素材，按住键盘 `Shift` 键点击另一个素材时，系统会自动将两个素材之间在当前过滤列表中的所有素材全部一次性选中（或随着第一个素材的状态批量取消选中）。

### 5. 移动端防抖 (Touch Actions)
- 当用户在移动端通过 `onTouchMove` 进行手指划动选择时，动态将网格及卡片的 `touch-action` 样式限制为 `none`，阻止了页面的阻尼回弹或纵向滚动干扰，体验非常丝滑。

### 6. 取消选择与全局操作优化 (Deselection & Floating Control Bar)
- **浮动控制条 (Floating Glassmorphism Bottom Bar)**：在底部居中添加了一个高颜值的磨砂玻璃悬浮控制栏。只要有素材处于选中状态，便会显现并展示“已选择 N 项”，并提供快捷的**取消选择**（大尺寸一键清除按钮）、**标记排期**以及**批量删除**操作。特别是在非宽屏（中等尺寸笔记本、平板或手机）侧边栏抽屉被隐藏时，为用户提供了完全无障碍的批量操作入口。
- **全选 / 取消全选工具按钮 (Select All Toggle)**：在搜索栏右侧新增了一键「全选 / 取消全选」当前过滤条件下的全部素材的快速操作按钮。
- **Esc 键键盘快捷取消**：支持标准的 `Escape` 按键。按 `Esc` 键可立即清空全部选中素材，或者清除当前的单素材聚焦状态，使桌面效率翻倍。

### 7. 取消选择体验全面优化 (Deselection Experience Upgraded)
- **卡片空白区域一键取消**：为素材库网格的整个空白背景区域添加了点击事件处理器，用户点击任意无卡片的空白地方即可一键清空多选状态。同时对所有卡片的交互增加了 `e.stopPropagation()` 防止冒泡误伤，实现了如 macOS Finder 和 Windows 资源管理器一般的清空交互。
- **复选框悬浮红叉指示**：在已被选中的卡片上，鼠标悬浮至左上角复选框时，蓝底白勾的标识会智能演变为红底白叉（`X`），醒目地提示用户“点击即可取消选择”。
- **工具栏新增「清除选择」按钮**：在搜索栏右侧新增了一个带有小红叉图标的「清除选择 (N)」常驻按钮，方便用户一目了然且便捷地一键清除所有已选项目。
- **草稿编辑面板附带「清空选择」**：在新建/编辑草稿面板的媒体区头部增加了「清空选择」快捷文字链接；并将已选图片右上角的小红叉按钮设为在移动端直接显示（`opacity-90`），电脑端仍然悬停展示（`opacity-0 hover:opacity-100`），解决移动设备无法通过 hover 移除图片的体验痛点。
- **草稿编辑面板选图红叉悬浮**：在草稿编辑底部的素材库列表中，已被勾选的素材在被鼠标悬浮时同样会展现红底白叉标识，交互体验与主素材库高度一致。

### 8. 排期发布与 To-Do 任务生成扩展 (Schedule Publish & Task Creation Extension)
- **支持主题与描述设定**：当用户选中素材点击「标记排期」时，系统会弹出磨砂玻璃设计的高颜值对话框，提示输入“帖子主题描述”（必填）和“详细要求”（选填）。
- **执行 Agent 智能派遣**：自动拉取并列出该品牌下绑定的所有 AI Agent。用户可以自由指定将生成任务派发给哪一位 Agent，默认选中品牌主理人（lead agent）。
- **To-Do 看板任务直接生成**：在确认生成时，后台除了自动将素材标记为 `['排期发布']`，还将直接向看板系统的 To-Do 列表中插入一条 `WorkUnit` 任务，自动携带 `[排期发布] [主题描述]` 的标题、所选素材的 URLs（映射到 materials 字段）和 assigneeID，让 AI 主动跟进内容撰写与排期工作，打通素材库到看板的完整自动化创作链路。
