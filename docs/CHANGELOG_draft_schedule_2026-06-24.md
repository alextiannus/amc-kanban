# 更新日志 - 素材库“准备草稿排期(idea)”功能升级 (2026-06-24)

## 背景与变更目的
为了进一步简化中小商家的自媒体运营路径，将素材库原有的“标记排期发布并生成 To-Do 任务”功能升级为**“准备草稿排期(idea)”**。
原流程在提交后会生成看板上的待办任务（Task），新流程提交后将**直接套用草稿模板生成对应的社交媒体 Post 草稿**，省去了任务认领与中转环节，大幅提高发布效率。

## 详细变更说明

### 1. 前端交互与界面文案升级 (`DashboardAssets.tsx`)
- **文案重命名**：
  - 侧边栏过滤器由“排期发布”变更为**“草稿排期”**。
  - 工具栏批量操作按钮、抽屉按钮及悬浮操作栏由“排期发布”或“标记为排期发布”统一变更为**“准备草稿排期(idea)”**。
  - 弹窗提交确认按钮重命名为**“生成 Post 草稿”**，加载状态提示为**“生成中...”**。
- **数据结构与筛选逻辑**：
  - 列表筛选及计数器更新为同时包含 `'草稿排期'` 和旧有的 `'排期发布'` 标签（兼容老数据）。
- **弹窗 UI 改版**：
  - 标题调整为 **“准备草稿排期 (Idea)”**，副标题为 **“将已选素材直接生成 Post 草稿，并指定渠道与发布时间”**。
  - 新增 **目标发布渠道账户 (Target Channel Account)** 下拉选择框（绑定到 `scheduleAccountId`，基于 `brandAccounts` 渲染）。
  - 新增 **建议排期时间 (Scheduled Time)** 日期时间选择器（绑定到 `scheduleDate`，`type="datetime-local"`）。
  - 将 **分配执行 Agent** 调整为可选（可以留空，仅生成草稿）。
  - 验证逻辑由必填 Agent 更改为**必填目标发布渠道账户**。

### 2. 后端 API 处理更新 (`route.ts`, `[draftId]/route.ts`)
- **标签清理**：
  - 在创建和修改草稿的 API 接口中（`/api/brands/[id]/drafts` 和 `/api/brands/[id]/drafts/[draftId]`），当生成草稿后，系统会将所关联素材的 `aiTags` 列表中包含的 `'排期发布'` 及 `'草稿排期'` 标签同时过滤并移除。

### 3. PRD 文档同步 (`docs/prd_amc.md`)
- 在极简素材库的“AI 自动化处理”小节中追加了“准备草稿排期(idea)一键生成”的核心业务流程定义，确保产品需求文档的一致性。
