# AMC 业务流程：从新商家上线到日常运营
*版本：v0.1 | 2026-06-17*

---

## 一、角色定义

| 角色 | 类型 | 定位 |
|------|------|------|
| **商家 / 客户** | 付费客户 | 餐厅老板，订阅 AMC 服务，提出品牌方向与素材，审核关键决策 |
| **AMC Agent** | AI | AMC 团队的 AI 执行层，对外以多个职能角色呈现：AI内容创作官 / AI市场调研官 / AI品牌策略师（Tier2+）/ AI私域运营官（Tier3）/ AI客服（Tier3）。负责具体执行：内容生产、发布、监控、回复、报告生成 |
| **AMC 品牌主理人** | AMC 内部人工 | 与特定 AMC Agent 长期固定搭档的专属人工对接人，统筹该 Agent 名下所有品牌的工作，处理需要人工判断/外联/到店协调的环节。对商家而言与 AMC Agent 同属"AMC 团队"，不强调人机分工 |
| **达人 / KOL** | 外部协作方 | 探店内容创作者，由品牌主理人筛选与对接，非 AMC 团队成员 |

> 协作原则（看板系统设计原则）：**AI Agent 做具体工作，人类（商家 + 品牌主理人）做过程监控与结果审批**。所有任务、草稿、素材均以 `brandId` 隔离，确保多品牌互不干扰。

---

## 二、整体流程总览

```
Phase 0  签约接入
   ↓
Phase 1  新品牌上线（Onboarding，约1-2周）
   ↓
Phase 2  日常内容生产循环（每日/每周，持续）  ←─┐
   ↓                                          │
Phase 3  评论与口碑管理（每日，持续）           │
   ↓                                          │
Phase 4  达人探店（按套餐频率，月/季度）         │
   ↓                                          │
Phase 5  月度复盘与优化  ───────────────────────┘
```

## 三、Phase 0：签约接入

| 步骤 | 执行者 | 说明 |
|------|--------|------|
| 1. 商家注册并选择套餐 | 商家 | 自助注册账号，选定 Essential / Growth / Scale 套餐，完成付款 |
| 2. 系统自动分配 AMC Agent | 系统 | 按 Agent+主理人 配对池，自动指派一个 AMC Agent 负责该品牌 |
| 3. 联动分配品牌主理人 | 系统 | 每个 AMC Agent 都固定搭档一位专属品牌主理人，Agent 一旦分配，对应主理人自动同步接入该品牌 |
| 4. 主理人主动联系商家 | AMC 品牌主理人 | 在收到新品牌分配通知后，主动联系商家，启动 onboarding 流程 |

> **Agent-主理人配对机制**：AMC 内部以"一个 Agent + 一位专属主理人"为协作单元长期搭档运作，而非一位主理人零散对接多个独立 Agent。这样可以保证主理人对所负责 Agent 的工作风格、品牌组合有持续、深入的掌握。

## 四、Phase 1：新品牌上线（Onboarding）

| 步骤 | 执行者 | 说明 |
|------|--------|------|
| 1. 品牌访谈 | 品牌主理人 ↔ 商家 | 了解品牌故事、定位、目标客群、主打产品、视觉调性偏好 |
| 2. 社媒账号接入 | 品牌主理人 + 商家 | 通过 PostFast OAuth Connect Link 完成 Instagram/Facebook/TikTok/小红书等官方授权（手动添加账号密码仅供本地模拟，不可用于真实发布） |
| 3. Google Maps 信息完善 | 品牌主理人 | 认领商家地址，完善营业信息 |
| 4. 品牌档案初始化 | AMC Agent | 调用品牌配置接口，查询绑定品牌列表 → 撰写品牌深度介绍（≥200字，融合访谈信息）→ 写入官网/电话/地址/时区等字段 → 系统自动创建专属 Lark Drive 共享目录 |
| 5. 初始素材提交 | 商家 | 提供菜单照片、Logo、品牌故事文档等基础素材 |
| 6. 素材入库 | AMC 主理人 / AMC Agent | 上传素材至素材库，打标签（含 AI 自动生成的描述/标签） |
| 7. 首月策略制定（Tier2+） | AMC Agent（品牌策略师角色） + 品牌主理人 | 竞品分析（前3名竞争对手）、目标客群画像、双语平台策略、品牌话术与视觉指南 → 与商家确认后定稿 |
| 8. 首月内容日历草拟 | AMC Agent | 生成首月内容排期草案 → 主理人/商家确认 |

**产出**：品牌档案完整、账号已连接、首月策略与内容日历就位，进入日常运营循环。

## 五、Phase 2：日常内容生产循环（每日/每周）

```
商家/主理人持续提供素材
   ↓
尽快安排探店，探店博主根据要求上传素材，补充素材库
   ↓
AMC Agent 每日扫描素材库"排期发布"标签
   ↓
自动生成内容草稿 → 任务状态置为 pending（主理人终审锁）
   ↓
品牌主理人审核草稿（看板 require_input 任务）
   ├─ 批准 → 进入排期发布
   ├─ 修改意见 → AMC Agent 重新生成
   └─ 拒绝 → 任务关闭，记录原因
   ↓
排期发布
   ├─ 大多数平台：通过后台渠道自动发布
   └─ 部分高风控平台：生成 require_input 任务，由品牌主理人手动完成发布（规避平台封号风险）
   ↓
到达排期时间，AMC Agent 验证帖子真实上线 → 记录发布链接 → 任务状态变为 done
   ↓
发布后品牌主理人立刻 review 帖子内容，并邀请商家查看
```

| 步骤 | 执行者 |
|------|--------|
| 周度素材提交 | 商家 |
| 安排探店补充素材 | 商家 + 达人 |
| 内容草稿生成 | AMC Agent |
| 草稿审核（autoPilot=false 时） | 品牌主理人 |
| 发布执行（含高风控平台手动发布） | AMC Agent / 品牌主理人 |
| 发布后review并邀请商家查看 | 品牌主理人 |

> 套餐差异：Starter 每月30条图文；Essential 每月≥20条图文+8条短视频，外加每月营销主题与团购转化活动策划；Scale 额外叠加付费广告创意制作与投放。

> **手动写草稿**：以上为 AMC Agent 自动生成草稿的默认路径。品牌主理人也可跳过自动生成环节，直接通过看板 `board_save_draft` 手动撰写/上传草稿（如节日特殊文案、商家临时指定内容），再走 `board_submit_draft` 进入与自动草稿相同的审核与排期发布流程，状态机不变。

## 六、Phase 3：评论与口碑管理（每日持续）

| 步骤 | 执行者 | 说明 |
|------|--------|------|
| 拉取评论 | AMC Agent（市场调研官/客服角色） | 每日批处理（如每日20:00）抓取各平台最新评论 |
| 分类处理 | AMC Agent | 好评：礼貌致谢；差评（≤3星）：道歉+解决方案，不挑衅不敷衍 |
| 自动回复 | AMC Agent | Tier2+ 全平台回复，工作日24小时内响应（Tier1 仅监控不回复） |
| 异常升级 | AMC Agent → 品牌主理人 | 遇凭证缺失或严重口碑危机，生成提醒任务并通知品牌主理人人工介入 |

## 七、Phase 4：达人探店（按套餐频率）

| 频率 | 套餐 |
|------|------|
| 每月4位博主 | Essential |
| 每季度24位博主（含大博主） | Growth |
| 每月2次头部KOL（10K+粉丝） | Scale |

```
AMC Agent 生成 require_input 任务，请求安排探店并上传素材
   ↓
品牌主理人 和商家协调好探店计划
   ↓
品牌主理人 在素人探店群和博主探店群，根据套餐需求发布探店任务
   ↓
品牌主理人 外联达人、确认到访时间
   ↓
商家 探店当天接待：备好主推菜品、优先出品、简单介绍品牌故事
   ↓
品牌主理人 跟进达人内容产出，审核是否符合 Brief
   ↓
品牌主理人 提交发布数据到 amc-kanban，AMC Agent 追踪发布数据
   ↓
数据纳入月度报告
```

**费用**：达人/KOL 费用已含在订阅服务费内，商家无需额外支付。

## 八、Phase 5：月度复盘与优化

| 步骤 | 执行者 | 说明 |
|------|--------|------|
| 1. 数据汇总 | AMC（市场调研官角色）Agent | 触达量、互动率、粉丝净增长、Google评分变化、表现最佳内容，汇总产出至 AMC 看板 |
| 2. 报告解读与反馈收集 | 品牌主理人 ↔ 商家 | 沟通关键发现，了解下月特殊安排（新品/活动），并将反馈通知 AMC Agent |
| 3. 品牌认知更新 | AMC Agent | 提交品牌认知更新：更新品牌档案与策略逻辑，沉淀长期记忆，下月内容更精准 |
| 循环 | 全员 | 回到 Phase 2，持续迭代 |

## 九、跨阶段支撑机制

- **看板任务生命周期**：`todo → in_progress → pending(require_input) → in_progress → done`，所有阻塞必须明确写出需要商家/主理人提供的内容，不允许无限重试或假装成功
- **多品牌隔离**：每个 Agent 可同时运营多个品牌，所有操作严格以 `brandId` 区分
- **异常处理**：API失败重试不超过2次，超限后转人工，且严禁在任务描述中暴露明文密钥
- **信息对称**：看板通过实时同步机制，让商家随时掌握 AMC 团队的工作进展，无需主动询问

## 十、已确认事项

1. **Phase 1 访谈模板**：在 AMC 学院内固化不同行业（如中餐/咖啡/烘焙等）的访谈模板，由 AMC Agent 和品牌主理人持续更新维护，不依赖单次人工临时整理。
2. **评论自动回复语气基调**：在品牌访谈阶段（Phase 1）确定，作为初始品牌语气基线写入品牌档案。
3. **达人筛选标准的品类差异化**：现阶段由品牌主理人凭经验筛选；中长期需先由 AMC（市场调研官角色）Agent 持续沉淀数据，待数据积累充分后再制定差异化筛选标准。
4. **月度报告解读流程**：是否标准化会议/电话由品牌主理人按品牌情况自行决定，会后需将会议记录与沟通内容更新同步给 AMC Agent，纳入品牌认知更新。
