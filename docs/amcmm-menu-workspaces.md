## 对话与 UI 契约

Kanban `ui-navigation.ts` 和 MM `assistant-navigation.ts` 使用同一页面目录，测试校验两份一致。`amc.context.uiCapabilities` 告诉 Assistant 当前实际可用入口；产物仅允许 `uiAction: {page, mode: open | suggest, month?}`，month 只适用于日历。

显式请求功能时 `open` 直接打开页面；可选建议 `suggest` 显示入口卡片。保留消息、未发送输入、任务回执与用户／品牌隔离，历史加载不自动跳转。跳转前立即持久化回复；后台结束或用户已关闭聊天时不抢占界面，之后可点入口卡片。页面打开沿用当前用户身份，不传入 AI 自定的品牌、URL、保存字段或业务执行参数。

页面打开不等于业务提交。保存、购买、排期、生成和发布继续由现有页面／服务完成并校验权限。Assistant 的下一轮只能依据已有事实或用户提供的信息，不把页面打开当执行回执。策划对话跳转后可在新页面继续原策划会话。
