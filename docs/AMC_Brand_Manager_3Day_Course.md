# 三天速成：AMC 品牌主理人上岗课程

*版本：v0.1 | 2026-06-18*
*受众：新入职 AMC 品牌主理人（非商家、非 AMC Agent 开发者）*
*目标：3 天内具备独立运营商家社媒账号的知识储备与系统操作能力，能上手承接 Phase 0-5 全流程工作*

---

## 课程总览

| Day | 主题 | 核心产出 |
|-----|------|---------|
| Day 1 | 行业认知：餐饮社媒运营的底层逻辑 | 能向商家讲清楚"为什么这样做"，建立专业可信度 |
| Day 2 | AMC 系统实操：看板、任务、草稿与发布全流程 | 能独立完成草稿审核、发布跟进、断连处理 |
| Day 3 | 核心运营场景：评论管理、达人探店、月度复盘 | 能独立带完一个品牌的完整月度循环 |

每天结构统一：**学习目标 → 知识点 → 实操练习 → 自测标准**。建议每天预留 3-4 小时学习+实操时间。

## Day 1：行业认知 — 餐饮社媒运营的底层逻辑

### 学习目标
完成 Day 1 后，你应该能够：
1. 向商家解释清楚为什么要在特定平台投入精力，而不是"什么都发一点"
2. 理解 2026 年主流平台（Instagram/TikTok/Facebook/Google Maps/小红书/大众点评）的算法偏好和内容方向
3. 理解差评/好评回复对本地搜索排名的真实影响，避免敷衍应对
4. 区分中文平台与西方平台运营逻辑的关键差异

### 知识点

**1.1 平台选择：少而精，而非全平台铺开**

多数表现优秀的餐厅只聚焦 2-3 个平台，而不是同时运营六个平台却样样平庸。AMC 的标准打法：
- **Instagram + Google Maps** 是绝大多数商家的核心两件套（视觉曝光 + 本地搜索决策）
- **TikTok** 适合愿意做短视频内容、目标客群偏年轻的品牌
- **小红书/大众点评** 适合面向华人客群、或大量游客/探店流量的商家
- Facebook 更多承担"老客户私域+活动通知"角色，而非新客获取主力

> 给商家的话术参考："我们不会把您的内容同时发六个平台拉低质量，而是先做透 1-2 个平台，把它做成获客主力，再逐步扩展。"

**1.2 Instagram / TikTok 算法在 2026 年关注什么**

- Instagram 算法核心围绕 **Reels + AI 理解内容**：系统会分析观看时长、评论情感、画面中出现的实际物体（如某道菜、某个场景），而不仅仅是点赞数。
- TikTok 算法核心是 **完播率** 和 "你会喜欢这个" 的预测式推荐——内容前 3 秒能不能留住人，比花多少预算更重要。
- 两者共同结论：**真实、未过度打磨的手机实拍内容，往往比精修广告片表现更好**。出餐瞬间、摆盘过程、调酒手法、后厨花絮，是高表现内容的典型素材。
- 发布节奏参考：**每周 3-5 条正式内容 + 每天 Stories**（Stories 对 Meta 系平台的账号活跃度权重很重要），Google Business Profile 建议每周至少 1 条更新。
- 算法奖励的是 **互动速度（发布后短时间内的互动量）、完播/停留时长、持续发布频率**，三者缺一不可。

**1.3 Google Maps 评论管理：不是客服礁，是搜索排名信号**

- 回复评论本身就是本地搜索排名的正向信号：研究显示，持续回复评论的商家未来获得评论的概率提升约 12%，平均评分在 6 个月内提升约 0.12 星。
- **好评回复**：点名感谢 + 提到具体菜品/体验细节（而不是"谢谢光临"模板句），能强化潜在顾客对该菜品的认知。
- **差评回复（≤3星）**：24 小时内响应，不辩解、不挑刺，说明具体改进措施，并尽量引导到线下/私信解决，避免在公开评论区拉锯。
- 遇到明显恶意/虚假评论，应通过平台举报渠道处理，而不是公开对线。

**1.4 中文平台特殊性：小红书 / 大众点评**

- 小红书餐饮类目营销投放规模在持续扩大，但行业普遍存在两个问题：**KOL 内容同质化严重**（多数商家反馈"水分"过重）、**多平台内容缺乏统一协调**。
- 用户对"真实消费体验"类笔记的信任度远高于单纯"打卡"类内容——这意味着达人探店 Brief 必须强调真实体验细节，而不是摆拍走流程。
- 因此 AMC 在小红书/大众点评的达人探店环节，要先做竞品和客群分析，再匹配达人，避免无差别撒网式投放。

### 实操练习

1. 选择一个真实或模拟的中餐品牌，写出你建议它优先运营的 1-2 个平台，并用一句话向"商家"解释理由（口语化，不要用术语堆砌）。
2. 找 3 条你认为"过度精修、表现可能不佳"的餐饮内容和 3 条"真实手机实拍、表现可能更好"的内容（可在 Instagram/TikTok/小红书上搜索同行案例），写出你判断的依据。
3. 模拟写出对以下两条评论的回复：
   - 一条 5 星好评，提到"招牌叉烧饭很好吃，服务也热情"
   - 一条 2 星差评，提到"等餐时间太久，菜也凉了"

### 自测标准

- 能否在不看资料的情况下，用 2 分钟向同事讲清楚"为什么不建议商家同时发六个平台"
- 差评回复练习中是否做到：不辩解、给出具体改进措施、引导线下沟通——三者缺一即不合格
- 好评回复练习中是否提到了具体菜品/细节，而非泛泛感谢

## Day 2：AMC 系统实操 — 看板、任务与发布全流程

### 学习目标
完成 Day 2 后，你应该能够：
1. 说清楚 AMC 团队的协作模型（AMC Agent + 品牌主理人 = 对商家透明的"一个团队"）
2. 理解看板任务生命周期，能正确判断何时该把任务标记为 `pending`、何时确认 `done`
3. 独立完成一次草稿审核、一次手动写草稿并提交的全流程
4. 能处理账号断连、发布失败等常见异常场景

### 知识点

**2.1 AMC 团队协作模型**

AMC 对外呈现为统一的"AMC 团队"，内部分工是：
- **AMC Agent（AI）**：负责具体执行——内容生产、发布、监控、评论回复、报告生成。对外以"AI内容创作官 / AI市场调研官 / AI品牌策略师（Tier2+）/ AI私域运营官（Tier3）/ AI客服（Tier3）"等职能角色呈现。
- **AMC 品牌主理人（你）**：与固定搭档的 AMC Agent 长期配对，统筹该 Agent 名下所有品牌，处理需要人工判断、外联、到店协调的环节。

> 核心原则：**AI 做具体工作，人类做过程监控与结果审批**。对商家而言，AMC Agent 和你同属一个团队，不强调"这是 AI 做的还是人做的"。

**2.2 看板任务生命周期（上板铁律）**

```
todo（待办） → in_progress（执行中） → pending（需要输入/审批）→ in_progress → done（完成）
                                                                              ↘ void（废弃）
```

- 任务必须携带 `deadline`（ISO 8601 格式，默认新加坡时区）和 `brandId`。
- 当任务卡在需要你审批/补充信息时，会进入 `pending` 状态，并在 `requiredInput` 字段写明需要你提供什么——这是你每天需要重点检查的列表。
- 只有当内容**真实发布到平台**（而不是仅仅排期成功）后，任务才会被标记为 `done`。
- 所有操作都以 `brandId` 隔离：你可能同时负责多个品牌，永远确认自己在操作哪个品牌的任务。

**2.3 内容发布全流程（你最常用的工作流）**

正常情况下，AMC Agent 每日扫描素材库，自动生成内容草稿，进入审核环节：

1. AMC Agent 调用 `board_save_draft` 保存草稿（关联 `accountId`），再调用 `board_submit_draft` 提交。
2. 看板出现 `pending`（require_input）任务，你需要打开草稿预览。
3. 你的三种选择：
   - ✅ **批准** → 进入排期发布
   - ✏️ **提交修改意见** → AMC Agent 重新生成
   - ❌ **拒绝** → 任务关闭并记录原因
4. 多数平台由系统自动发布；**高风控平台**（容易被风控误判封号的平台）会生成一个 `require_input` 任务，需要你手动完成发布动作。
5. 到达排期时间后，系统会验证帖子是否真实上线，确认后回填发布链接，任务状态变为 `done`。
6. **发布后你需要立刻 review 一次内容效果，并邀请商家查看**——这是商家体验感的关键一步，不要省略。

**2.4 手动写草稿（不依赖自动生成的情况）**

遇到节日特殊文案、商家临时指定内容等场景，你可以跳过 AMC Agent 自动生成环节：
1. 直接调用 `board_save_draft` 手动撰写/上传草稿（必须传入 `accountId`）
2. 调用 `board_submit_draft` 提交
3. 之后进入与自动草稿完全相同的审核与排期发布流程，状态机不变。

**2.5 常见异常处理**

| 场景 | 处理方式 |
|------|---------|
| 账号显示"断连" | 进入配置中心找到该账号 → 点击"重新授权"→ 重新完成 PostFast OAuth 流程 → 确认状态恢复"已连接" |
| 发布/排期提交失败 | 任务会被标记为 `pending`，查看详细接口错误信息，必要时联系技术支持，不要重复无限重试（系统最多重试 2 次后会停止并转人工） |
| 缺乏平台官方 API 凭证（如 Instagram DM） | 不能假装已处理；应创建 `sentiment_alert` 类型的待办任务，写明缺失的凭证清单，并通过 `lark_notify` 提醒自己跟进 |
| 看板没有新任务 | 检查当月 Brief 是否已提交（无特殊安排时 AMC 会按默认策略执行） |

**2.6 关键工具速查（你会高频接触的）**

| 场景 | 工具 | 要点 |
|------|------|------|
| 查看品牌绑定的社媒账号 | `board_list_social_accounts` | 创作内容前必须先确认有效 `accountId` |
| 保存/修改草稿 | `board_save_draft` | 必须传 `accountId` 和 `brandId` |
| 提交草稿进入审批/发布 | `board_submit_draft` | 系统按 `autoPilot` 设置自动选择直发或走审批 |
| 查看已发布/排期内容 | `board_list_published_content` | 用于确认排期是否被成功接受 |
| 取消已排期内容 | `board_delete_scheduled_content` | 计划变更时使用 |
| 生成账号授权链接 | `board_generate_account_connect_link` | 商家需要连接新账号时使用 |
| 给自己/团队发提醒 | `lark_notify` | 阻塞、催审、严重异常时主动提醒 |

### 实操练习

1. 在测试环境中，模拟审核一条 `pending` 状态的草稿任务：分别走一次"批准"、一次"提交修改意见"的完整路径，记录状态变化。
2. 手动写一条草稿（任选主题，如"中秋节特别菜单"），完整走完 `board_save_draft → board_submit_draft` 流程。
3. 模拟一次账号断连场景，写出你会按什么顺序处理（不需要实际操作真实账号）。

### 自测标准

- 能否准确说出任务从 `todo` 到 `done` 之间所有可能的状态节点
- 能否解释清楚"高风控平台需要手动发布"背后的原因（规避平台误判封号）
- 遇到缺乏 API 凭证的场景时，是否知道正确做法是创建提醒任务而不是假装处理完成

## Day 3：核心运营场景实操 — 评论管理、达人探店、月度复盘

### 学习目标
完成 Day 3 后，你应该能够：
1. 独立执行评论批处理工作流，区分自动回复与需要人工介入的场景
2. 主导一次完整的达人探店流程，从筛选到数据归档
3. 解读月度报告，并能就此与商家进行有效沟通
4. 完整带完一个品牌的月度运营循环（Phase 2 → Phase 5）

### 知识点

**3.1 评论与口碑管理（每日批处理，参考晚 8 点）**

工作流程：
1. 拉取各平台最新评论（Google 用 `google_get_reviews`，其他平台如 Yelp 用 `board_reply_review`）
2. 分类处理：好评礼貌致谢；差评（≤3星）道歉+给出解决方案，不挑衅不敷衍
3. 接口提交回复：Google 评论优先直连 `google_reply_review`；其他平台统一走 `board_reply_review`
4. **Tier1 套餐仅监控不回复**，Tier2+ 才是全平台自动回复，工作日 24 小时内响应
5. 遇到凭证缺失或严重口碑危机（如连续多条差评、负面话题发酵），生成提醒任务并主动通知，不能让问题自己"过去"

**3.2 达人探店全流程（你主导外联和接待协调的环节）**

探店频率因套餐而异：

| 套餐 | 频率 |
|------|------|
| Essential | 每月 4 位博主 |
| Growth | 每季度 24 位博主（含大博主） |

完整流程：

```
AMC Agent 生成 require_input 任务，请求安排探店并上传素材
   ↓
你和商家协调探店计划
   ↓
在探店任务群发布探店任务（按套餐需求匹配博主层级）
   ↓
外联达人、确认到访时间
   ↓
商家接待当天：备好主推菜品、优先出品、简单介绍品牌故事
   ↓
你跟进达人内容产出，审核是否符合 Brief
   ↓
提交发布数据到看板，AMC Agent 追踪发布数据
   ↓
数据纳入月度报告
```

**关键提醒**：
- 达人/KOL 费用已含在订阅服务费内，商家无需额外支付——这是常见的商家疑问点，要主动讲清楚。
- 参考 Day 1 知识点 1.4：探店 Brief 要强调真实体验细节，避免同质化"打卡"内容，这会直接影响达人探店内容在小红书等平台的可信度和转化效果。
- 达人筛选标准目前依赖你的经验判断（粉丝量、互动率、内容风格三维评估），中长期会由数据沉淀逐步标准化。

**3.3 月度复盘与品牌认知更新**

1. **数据汇总**：AMC Agent 汇总触达量、互动率、粉丝净增长、Google 评分变化、表现最佳内容，写入看板
2. **报告解读与反馈收集**：你与商家沟通关键发现，了解下月特殊安排（新品/活动），并把反馈同步给 AMC Agent
3. **品牌认知更新**：AMC Agent 据此更新品牌档案与策略逻辑，沉淀长期记忆，下月内容会更精准
4. 循环回到 Phase 2，持续迭代

报告解读重点指标参考：
- 总触达人数（Reach）
- 互动率（Engagement Rate）：点赞+评论+分享 / 触达，**>3% 为良好水平**
- 粉丝净增长（新增 - 流失）
- Google Maps 评分变化
- 表现最好的 3 条内容——这是最重要的部分，要总结出规律并反馈给 AMC Agent，让下月内容更精准

### 实操练习

1. 模拟处理 3 条评论的批处理流程：1 条好评、1 条 3 星差评、1 条疑似恶意评论，写出你对每一条的分类判断和处理动作。
2. 写一份探店 Brief 草稿（任选一个中餐品牌+一个达人层级），包含：必拍内容清单、话题标签、发布要求，并体现"真实体验"而非"摆拍打卡"的要求。
3. 拿到一份模拟月度数据（互动率 2.1%，粉丝净增长 -15，Google 评分从 4.3 降到 4.1），写出你会如何向商家解读这份报告，以及你会建议下月做哪些调整。

### 自测标准（课程综合验收）

完成三天课程后，你应该能够独立通过以下场景测试：
1. 给定一个全新品牌，能说出 Phase 0 到 Phase 5 的完整流程节点，以及每个节点谁是执行者
2. 能在不查阅资料的情况下，正确判断一条草稿任务该批准、该打回修改、还是该拒绝
3. 能写出一条符合标准的差评回复（不辩解、给出具体改进措施、引导线下沟通）
4. 能解释清楚为什么互动率 2.1%（低于 3% 良好线）+ 粉丝净增长为负，需要在下月策略中做出调整，并给出至少 2 个具体调整方向
5. 遇到账号断连、凭证缺失、发布失败三类异常时，能分别说出正确处理路径

> 通过以上 5 项验收，即视为完成"AMC 品牌主理人上岗"标准，可独立承接品牌全流程运营工作。建议由资深主理人或团队负责人对新人进行一次实际验收谈话。
