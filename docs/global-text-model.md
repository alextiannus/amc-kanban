# 全局文本模型（开发中，尚未上线启用）

Kanban、Content、MM 共用 Kanban 管理的全局文本策略。管理员新增 LLMConfig 连接，验证文本、JSON、多轮与工具能力，预检三个系统后应用或恢复上一版本。供应商名称与协议分离；同协议连接不需要改代码。

严格策略覆盖纯文本调用的任务映射、平台映射、显式模型及供应商备用路由。多模态理解和媒体生成仍使用原配置。策略关闭时沿用旧路由。新的请求/作业绑定版本；同一请求/作业内的调用和工具循环不随中途切换而改变。失败不得请求其他供应商。

连接密钥仅存 LLMConfig。已应用的连接禁止直接改写或删除，换密钥/地址须创建新连接再验证切换，以确保历史版本和运行中作业引用稳定。策略、验证报告与调用日志不复制密钥。数据库版本更新使用比较并交换及审计。

内部接口 /api/internal/global-text 提供协议版本、绑定策略快照、文本/消息/工具请求和诊断。Content、MM 使用服务认证；工具执行仍由原业务处理。预检必须从 Content、MM 实例回连 Kanban 并验证同一候选连接，不能仅证明 Kanban 单机联网。

部署顺序：迁移（策略关闭）→ Kanban → Content/MM → 三系统预检 → 启用。只有三系统新生成记录均确认成功后才宣布上线完成。真实调用日志只含目标/响应模型、系统、任务、版本、耗时和状态，不存提示词、输出正文或密钥。
