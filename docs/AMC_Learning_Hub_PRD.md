## 一、背景与目标

AMC 的核心挑战之一是：主理人不知道如何充分使用这个系统，导致合作体验不佳、续订率下降。

AMC Learning Hub 的目标：
- 降低主理人的上手门槛
- 提升主理人对 AMC 能力的认知和使用深度
- 建立 AMC 作为"专业营销伙伴"的品牌感
- 为 AMC 自身提供一个内容营销和产品扩展的入口

### 3.2 User Manual（使用手册）

**定位**：AMC 的正式用户操作手册，面向主理人，包含系统功能说明、操作步骤图解，以及标准化的 SOP（Standard Operating Procedures）。目标是让主理人无需依赖客服支持，能独立完成所有标准操作。

**内容结构**：

---

#### Part 1：系统概览与工作循环

**1.1 AMC 是什么与角色定位**
- **团队共建**：AMC（AI Marketing Crew）是一个整体的智能营销团队，包含 **AMC Agent**（AI 智能体同事）与 **AMC 主理人**（人类经理）。在 AMC 中，Agent 与主理人都是团队不可分割的一员。
- **同事关系**：作为主理人，你应当把 AMC Agent 当作你的工作同事。两者紧密协作，共同为品牌客户的营销效果负责。
- **职责分工**：由 Agent 负责海量数据抓取、创意发散、内容草稿生成和自动化发布，而主理人负责全局的方向指导、人脉与线下运营落地，并牢牢把控终审权。

**1.2 与 AMC Agent 同事的工作循环**

在一个新品牌开工（Onboarding）之后，主理人将 AMC Agent 视作同事，按照以下标准循环流程展开人机协作：

```
新品牌开工
  ↓
1. 讨论策略 ➜ 开工后主理人首先与 AMC Agent 讨论品牌的定位、目标客群及主打策略
  ↓
2. 整理素材 ➜ 根据讨论的策略，主理人收集并整理品牌素材（如图片、视频、基本文案信息）并提供给 Agent
  ↓
3. 制作草稿 ➜ AMC Agent 依据策略和素材开始生成内容草稿，若需要确认则自动生成 Require Input 任务
  ↓
4. 排期发布 ➜ 草稿通过主理人审核后进入排期，由系统/Agent 自动发布到各大社交媒体平台
  ↓
5. 检验结果 ➜ 帖子发布后，主理人与 AMC Agent 共同检视发布效果，查看数据分析报告
  ↓
6. 策略优化 ➜ 根据检验结果复盘，调优下一阶段的内容方向，并重新回到步骤 1 讨论下一轮策略，持续循环
```

> **策略调优**：在每次循环中，**AMC Agent 会不断更新对品牌的理解并进行策略调优**（其学习成果会持续积累在品牌的专属记忆 profile 中）。合作时间越长，Agent 产出的方案和内容会越来越懂你的心意。

**1.3 看板介绍**
- 各功能区说明（内容看板、社媒账号、数据报告、配置中心）
- require_input 任务是什么，如何处理
- 通知机制说明

**1.4 账号权限说明**
- 客户账号 vs AMC 团队账号的权限区别
- 多门店 / 多品牌管理说明

#### Part 2：账号接入操作

**2.1 社交媒体账号接入（核心 SOP）**

> **SOP-001：通过 PostFast OAuth 接入社媒账号**
>
> 适用场景：首次接入 Instagram、Facebook、TikTok、小红书等平台账号
>
> 步骤：
> 1. 进入 AMC 配置中心 → 社媒账号管理
> 2. 点击"添加账号"→ 生成 PostFast Connect Link
> 3. 点击链接，跳转 PostFast 页面
> 4. 选择平台，完成 OAuth 官方授权
> 5. 返回 AMC，刷新控制台，账号自动同步出现
>
> 注意：手动添加账号（填写账号密码）不能用于内容发布，仅用于本地自动化脚本。

**2.2 账号断连处理（SOP）**

> **SOP-002：社媒账号断连重新授权**
>
> 触发条件：账号状态显示"断连"或内容发布失败
>
> 步骤：
> 1. 进入配置中心，找到断连账号
> 2. 点击"重新授权"→ 重新完成 PostFast OAuth 流程
> 3. 确认状态恢复为"已连接"

#### Part 3：日常协作 SOP

**3.1 月度 Brief 提交**

> **SOP-003：月度 Brief 提交流程**
>
> 执行频率：每月第一个工作日
>
> 步骤：
> 1. 打开看板 → 点击"新建 Brief"
> 2. 填写：本月新品（如有）、促销活动（如有）、特别强调的内容方向
> 3. 上传相关参考图或素材（可选）
> 4. 提交，AMC 在 24 小时内确认并调整本月内容计划
>
> 没有特殊安排时，AMC 按品牌默认策略执行，无需提交 Brief。

**3.2 素材提交规范**

> **SOP-004：周度素材提交**
>
> 执行频率：每周一次，建议每周一提交
>
> 素材要求：
> - 图片：3–5 张，JPG/PNG，自然光，建议 1080×1080px 以上
> - 视频：1–2 条，MP4，15–60 秒，手持拍摄即可
> - 新品/活动素材：提前至少 5 天提交
>
> 提交方式：看板素材上传区 或 直接发送至品牌 WhatsApp 群

**3.3 内容草稿审核**

> **SOP-005：内容草稿审核流程**
>
> 触发条件：看板出现"待审核"状态的 require_input 任务
>
> 步骤：
> 1. 打开看板 → require_input 任务列表
> 2. 点击草稿预览，确认内容、图片、话题标签
> 3. 选择：✅ 批准发布 / ✏️ 提交修改意见 / ❌ 拒绝并说明原因
> 4. AMC 在修改后重新提交，或直接按计划发布
>
> 建议：当天收到当天处理，避免发布断档。

**3.4 月度报告解读**

> **SOP-006：月度绩效报告查看**
>
> 触发条件：每月月初收到上月报告通知
>
> 重点关注指标：
> - 总触达人数（Reach）：内容被看到的总次数
> - 互动率（Engagement Rate）：点赞+评论+分享 / 触达，>3% 为良好
> - 粉丝净增长：本月新增 - 流失
> - Google Maps 评分变化
> - 表现最好的 3 条内容（学习规律，告知 AMC 多做此类内容）
>
> 行动：月底看完报告后，更新下月 Brief 方向。

---

#### Part 4：达人探店 SOP

> **SOP-007：达人探店完整执行流程**
>
> 执行频率：每月（Essential套餐）/ 每季度（Growth套餐）/ 每月头部KOL（Scale套餐）
>
> **AMC 团队全程负责：**
> - 达人筛选（粉丝量、互动率、内容风格三维评估）
> - 制作探店 Brief（必拍内容清单、话题标签、发布要求）
> - 达人外联与时间确认
> - 探店当日对接与跟进
> - 达人内容审核与发布协调
> - 数据追踪与报告
> - **所有达人费用已含在订阅套餐内，客户无需额外支付**
>
> **客户需要做的事：**
>
> 步骤 1：收到 AMC 看板通知（require_input 任务）→ 确认本次探店时间窗口（2分钟内完成）
>
> 步骤 2：探店当天
> - 提前备好本次主推菜品
> - 安排优先出品，确保呈现最佳状态
> - 简单介绍品牌故事（AMC 会提前发送话术参考卡）
>
> 步骤 3：探店结束后
> - 若有客户自己拍摄的额外素材，可上传至看板素材库（可选）
>
> *其余一切由 AMC 团队负责处理。*

#### Part 5：常见故障排除

| 问题 | 可能原因 | 解决步骤 |
|------|---------|---------|
| 内容没有按时发布 | 账号断连 | 执行 SOP-002 |
| 看板没有新任务 | 当月 Brief 未提交 | 执行 SOP-003 |
| 达人内容与品牌不符 | Brief 说明不够具体 | 联系 AMC 更新达人 Brief 模板 |
| 月度报告数据异常 | 账号数据同步延迟 | 等待 24 小时后刷新；如仍异常联系 AMC |

### 3.3 Skill Hub（技能中心）

**定位**：AMC AI Agent 的技能库。由 AMC 团队精心筛选整理的高质量技能包，供 AMC Agent 按需下载安装，扩展执行能力。**完全免费**，不向商家收费。

**核心理念**：Skill Hub 不是给商家买的商店，而是 AMC Agent 的"工具箱"——Agent 根据品牌需求，自主选择安装最合适的技能包，提升执行质量。

**技能包分类**：

#### 营销技能（Marketing Skills）
- 📊 竞品社媒分析 — 抓取并分析竞品账号内容策略、互动率、发布节奏
- 🏷️ 团购转化策略 — 团购活动设计、文案生成、上线推广流程
- 🌟 口碑管理 — 评论监控、好评引导、差评危机处理 SOP
- 🗺️ Google Maps 优化 — 关键词优化、照片更新策略、评分提升打法
- 📅 营销日历自动规划 — 基于节假日与品牌节点自动生成营销排期

#### 内容创作技能（Content Writing Skills）
- ✍️ 多平台文案生成 — 针对 Instagram / 小红书 / Facebook / TikTok 各平台调性生成文案
- 🎬 短视频脚本创作 — Reels / TikTok 脚本，15–60 秒，适配本地华人餐饮场景
- 📸 图文排版模板 — 预设品牌视觉风格，一键生成发帖格式
- 🎉 节日营销文案库 — 春节 / 中秋 / 圣诞 / 情人节等节点专用模板
- 🍜 新品上线内容包 — 新品发布倒计时系列内容脚本

#### 自我提升技能（Self-Improvement Skills）
- 🧠 品牌记忆强化 — 自动从历史互动中提炼品牌偏好，更新 brandcontext.md
- 📈 数据复盘分析 — 月度内容绩效分析，识别高表现内容规律并提炼策略
- 🔍 趋势感知 — 定期扫描本地餐饮 / 社媒热点，输出可用素材灵感
- 💬 私域运营语料 — WhatsApp / 微信群互动话术库，提升私域响应质量

#### 其他热门技能（Popular Skills）
- 🌐 中英双语本地化 — 自动将中文内容适配为本地英文语境，覆盖华人与本地客群
- 👥 达人筛选助手 — 根据粉丝量 / 互动率 / 内容风格自动生成达人候选名单
- 📝 require_input 摘要助手 — 将复杂背景任务压缩为主理人易读的决策摘要

**访问权限**：所有 AMC 订阅用户均可查看 Skill Hub，了解 Agent 已安装的技能及运行状态。

**技术形式**：卡片式展示 + 已安装/未安装状态标签 + Agent 一键安装 + 每个技能包含简介与使用场景说明

### 3.4 AMC School（AMC 学院）

**定位**：帮助主理人提升社媒运营认知，成为更好的 AMC 合作伙伴，同时建立 AMC 的行业权威性。

**内容结构**：

#### 入门课程
- 课程 01：为什么餐厅需要社媒运营？
- 课程 02：新加坡餐饮平台全解析（Instagram/TikTok/小红书/Google Maps）
- 课程 03：如何拍出让人流口水的食物照片（手机实操）
- 课程 04：你的第一个月：AMC 会为你做什么

#### 进阶课程
- 课程 05：Instagram 算法怎么工作
- 课程 06：如何写出让本地人想来吃饭的文案
- 课程 07：达人探店完全指南
- 课程 08：用 Google Maps 评论驱动新客到店

#### 案例研究
- 一家新开中餐厅如何 3 个月涨粉 2,000
- 一条 Reels 带来 50 桌预订的完整复盘
- 差评危机处理：从 3.8 分到 4.6 分的 6 个月

#### 营销日历
- 新加坡全年节假日营销时间表（华人节日 + 本地节假日）
- 每个节点的内容建议和准备时间提醒

**技术形式**：文章/视频混合 + 完成进度追踪 + 收藏 + 搜索
