# Service Plan Scoping

## Rule

Every growth plan must separate:

1. Best recommended strategy.
2. Work included in the merchant's subscribed AMC plan.
3. Upgrade discussion items.
4. Merchant inputs needed before execution.

## Required Checks

Before updating `growth-plan.md`:

1. Read `profile.md`.
2. Find `amc_plan`.
3. Read `knowledge/service-plans/{plan}.md` or the closest matching plan.
4. Scope implementation to that plan.

## Essential Plan Pattern

Essential can include:

- Merchant positioning.
- Basic platform audit recommendations.
- First batch content briefs.
- Google Maps lightweight update suggestions.
- Basic review notes.
- Light content direction.

Usually upgrade items:

- Multi-store account operations.
- KOC/influencer coordination.
- Paid ads.
- Private-domain operations.
- Deep menu/pricing analytics.
- High-touch weekly campaign management.
- Multi-brand rollout.

## Output Language

Use explicit labels:

- `Essential:`
- `升级探讨:`
- `当前 Plan 内实施工作`
- `最佳推荐方案`

Do not imply upgrade work is included in the current subscription.
